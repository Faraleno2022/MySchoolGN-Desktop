# MySchoolGN Desktop

Ce dépôt contient uniquement les installateurs officiels de MySchoolGN Desktop, publiés dans les [Releases](https://github.com/Faraleno2022/MySchoolGN-Desktop/releases).

À partir de la version 1.3.8, MySchoolGN vérifie ce dépôt et propose automatiquement les nouvelles versions. Chaque installateur est accompagné de son empreinte SHA-256, contrôlée avant installation.

Mise à jour manuelle : fermer MySchoolGN puis exécuter le dernier `MySchoolGN_Setup_vX.Y.Z.exe`. Les données, licences, médias et configurations locales sont préservés.
